# 🤖 Мой ИИ-Агент-Уборщик (AI Agent)

Этот проект — персональный ИИ-агент, который работает на старом ноутбуке (Simply Linux 10.4, 32-bit) и помогает следить за порядком в системе.

## ✨ Возможности
- **Общение**: Понимает вопросы и отвечает благодаря GigaChat API (облачная нейросеть).
- **Проверка места**: Показывает, сколько свободно на диске.
- **Поиск больших файлов**: Находит топ-5 самых тяжелых файлов в домашней папке.
- **Поиск и удаление скриншотов**: Находит старые скриншоты (старше 14 дней) и удаляет их *только после подтверждения* пользователем.
- **Авто-проверка**: Каждую пятницу в 18:00 автоматически собирает отчет о состоянии системы и сохраняет его в файл `last_report.txt`.

## 🚀 Как запустить
1. Откройте терминал.
2. Перейдите в папку проекта: `cd ~/ai_agent`
3. Активируйте виртуальное окружение: `source venv/bin/activate`
4. Запустите агента: `python3 main.py`
5. Для выхода напишите `выход`.

## 📂 Структура проекта
- `main.py` — главный файл запуска и диалога.
- `agent.py` — логика общения с GigaChat и вызова инструментов.
- `tools.py` — сами инструменты (проверка диска, поиск, удаление файлов).
- `auto_check.py` — скрипт для автоматической проверки (без нейросети).
- `.env` — файл с секретными ключами (НЕ загружается в Git!).

## ⏰ Автоматический запуск (Cron)
Задача настроена в `crontab`. Проверить расписание: `crontab -l`.
Отчеты сохраняются в `last_report.txt`, логи запуска — в `cron_log.txt`.

## 🔒 Безопасность
- Ключи API хранятся в `.env` и не попадают в публичный доступ.
- Удаление файлов происходит только после явного подтверждения словом "Да" и только в папке "Изображения".
